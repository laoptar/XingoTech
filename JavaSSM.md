  四、核心设计要点

  单平台登录机制 (AuthServiceImpl.java:48-49)：
  - 用户登录时，先调用 userTokenDao.deactivateByUserId() 将该用户所有活跃令牌设为 status=0
  - 然后生成新 JWT 令牌并插入 user_token 表
  - 效果：同一用户在新设备登录后，旧设备的令牌立即失效

  API 使用方式：
  # 登录
  POST /auth/login?username=xxx&password=xxx&platform=web
  → 返回 { "code":200, "token":"eyJhbG...", "user":{...}, "platform":"web" }

  # 访问受保护资源（User CRUD）
  GET /user/list
  HEADER: Authorization: Bearer eyJhbG...

  # 注销
  POST /auth/logout
  HEADER: Authorization: Bearer eyJhbG...

  安全说明：JwtUtil 的 HS256
  密钥当前在类加载时随机生成，服务重启后已有令牌会失效。生产环境建议将密钥写入配置文件持久化。
